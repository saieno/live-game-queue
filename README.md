# live-game-queue

The live game queue for [twitch.tv/retrosaieno](https://twitch.tv/retrosaieno).

* `index.html` - the page: the stream, what is playing now, and the queue
* `queue.json` - the same thing as data: schema-versioned, explicitly ranked,
  with the Now Playing title, the resolved platform theme and whether the queue
  is currently locked
* `game_queue.json` - the raw request array, exactly as the bot writes it

Generated by `arcade_publish_queue.py` on a 5-minute cadence, and only when the
content actually changed. Static snapshot: the page makes no network requests of
its own beyond the embedded Twitch player.
